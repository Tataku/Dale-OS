# Dale OS — Second Brain Ingestion Packet v0.1

## Source status

Owner-authorized project build. This packet contains project-level synthesis only. No personal financial values, credentials, ACF proprietary scoring formula, or private customer data.

## Project identity

**Dale OS** is an agentic operating system for high-integrity software and finance. It grew from durable rules developed while operating AI coding agents and building ACF Dashboard.

The public thesis is not "better prompts." It is **trustworthy autonomy**: constrain authority, preserve uncertainty, prove financial truth, and make completion claims correspond to real state transitions.

## Canonical principles

- Authority before autonomy.
- Real fixes to real problems.
- Null is not failure. False certainty is.
- Get the money right.
- The model is not the calculator.
- Preview before mutation.
- Stop is a successful outcome.
- Scope-OUT matters.
- Latest authority carries forward.
- Claims require state transitions.
- Every failure should improve the operating system.

## Architecture decision

Dale OS is the canonical operating system. Skills are modules inside it.

Canonical skills use portable Agent Skills directories. Framework-specific distributions are generated adapters. Eve is the first full reference adapter, not the source of truth.

## Public positioning direction

Lead with the repo and evidence, not self-declared expertise.

Core language:

- "Authority before autonomy."
- "Get the money right."
- "Make agents harder to fool. Make financial systems harder to lie."
- "Built with institutional-style discipline for provenance, accounting integrity, auditability and human authority."

Avoid factual certification language such as "RIA compliant" or "institutional grade" until an evidence/review process supports those exact claims.

## Public/private boundary

Public: generalized rules, sanitized mechanisms, synthetic fixtures, portable skills, deterministic tools, evals.

Private: personal financial data, brokerage records, credentials, proprietary ACF scoring formulas/weights, private beta/customer data, unnecessary internal security detail.

## Current phase

v0.1 private foundation and hardening.

Next gates before public: live model evals, activation tuning, privacy/security scrub, license selection, fresh-eyes README test, reproducible benchmark results, launch assets.

## Strategic relationship to ACF

Dale OS should stand on its own technically. ACF appears as the real system that generated and exercises the doctrine, not as an advertisement inserted into every skill.

Desired funnel: developer discovers a useful operating skill → sees Financial Truth → recognizes the system came from consequential finance software → discovers ACF.

## Contradictions / tensions to preserve

- Public authority positioning vs overclaiming: resolve toward evidence-first positioning.
- Broad OS vs skill simplicity: keep skills narrow and compose them at the OS layer.
- Portability vs framework-native UX: one canonical source, generated adapters.
- LLM intelligence vs accounting authority: deterministic math and evidence gates outrank fluent inference.
