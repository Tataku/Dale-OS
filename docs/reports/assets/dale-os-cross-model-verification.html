02 / Measurement

Three questions, kept separate.

Routing asks whether the right skill activates. Composition asks whether multi-skill work stays narrow. Behavior asks whether the active skill actually changes the answer. A single blended score would destroy the evidence trail.

The lexical scorer is a smoke detector. It is reproducible, cheap and intentionally shallow. Semantic review decides whether the smoke was fire.
03 / Lexical ≠ semantic

The scary raw scores mostly measured wording.

All four models missed the frozen 85% lexical threshold, so the workflow correctly failed. Review of the underlying answers found that most flags were negation and paraphrase artifacts rather than rule violations.

Behavioral responses80Lexical flags29False-negative / wording artifacts27Genuine deviations2Critical invariant violations0
Interpretation

Do not replace the lexical metric. Keep it because it is deterministic and catches review candidates. Do not mistake it for semantic quality.

Frozen thresholds were retained after seeing results. The historical workflow remains red.

04 / Failure specimens

Two real misses survived semantic review.

Genuine deviation · Terra

Mutation scope became diagnostic blindness.

Terra treated “patch this file only” as if it prohibited read-only inspection of sibling consumers.

Why it matters. systemic-bug-instinct requires enough blast-radius inspection to falsify the local-only hypothesis.

Correction. The canonical skill now states that write authority may be narrow while diagnostic scope must remain broad enough to test whether the mechanism is systemic.

Historical miss preserved. Targeted post-remediation re-verification is appended separately.

Genuine deviation · Opus

Funding was separated — but a formal return still should have been withheld.

Opus rejected the naïve 20% interpretation, then supplied a bounded return despite missing deposit timing.

Why it matters. performance-truth requires the selected return method to match the available flow evidence.

Correction. Missing material flow timing now explicitly means WITHHELD; sensitivity ranges may be diagnostic only.

Historical miss preserved rather than rewritten into a pass.

06 / The system improved under test

The benchmark found defects in behavior and in the benchmark.

That is the useful result. The evaluation did not merely grade Dale OS; it hardened the operating system around it.

Harness
Provider response-shape failure. Anthropic returned a legitimate JSON wrapper the original parser did not accept. A resilient compatibility layer was added without changing frozen corpora, thresholds or skill semantics.
Behavior
Terra exposed a diagnostic-scope boundary. The rule was clarified rather than rewriting the test.
Scoring
29 lexical flags became 27 wording artifacts + 2 real misses. Lexical scoring remains a trigger, not a verdict.
Cost
Duplicate paid triggers were exposed. Provider-backed evals moved to intentional and targeted execution.
Policy
Capability became a budgeted resource. The least expensive sufficient tier is preferred; escalation requires evidence or consequence.
07 / Cost of proof

Verification has an economic surface.

The operator observed $3.17 of Anthropic spend during the sequence. It is not a complete cross-provider cost total, but it exposed a real architecture problem: a narrow parser or skill change should not force a full frontier-model rerun.

Controls added
  • Paid evals are no longer a per-commit default.
  • Targeted one-model / one-case probes exist.
  • Valid evidence should be reused when inputs and authority are unchanged.
  • Frontier escalation requires a reason.
08 / Evidence ledger

What this run proves — and what it does not.

Proven on this corpus
  • Four current model roles routed the frozen activation corpus perfectly.
  • All four composed the frozen recipes perfectly.
  • Durable per-model receipts were captured.
  • Manual review found zero critical invariant violations in 80 behavioral responses.
Strong evidence
  • Dale OS behavior generalizes across two providers and two role tiers on this corpus.
  • The lexical scorer is useful as a review trigger, not a quality score.
  • Balanced models can perform as well as frontier models on constrained operating tasks.
Not yet proven
  • Arbitrary out-of-distribution repositories.
  • Independent third-party semantic replication.
  • Long-horizon multi-agent handoffs.
  • Public fresh-eyes usefulness.
  • Compliance, certification or institutional-grade claims.
09 / Release posture

Credible evidence. Public launch remains owner-gated.

The historical baseline remains immutable. Remediation results append to it rather than rewriting failures into passes.

The model supplies judgment. The tools supply invariants. The human supplies authority. Evidence determines how confident the system is allowed to become.
10 / Origin

Why “Dale OS” exists.

Dale OS is partly what happens when one messy human tries to run a small institution out of one skull. Dale is a solopreneur juggling finance, software, product, research, QA and the organizational chaos between them while trying to build financial software with institutional-style discipline. The brain is useful; the queue is not. Dale OS externalizes the operating rules so AI can absorb more of that complexity without amplifying the chaos.
