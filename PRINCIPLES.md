# Principles

This is the part I care about most. The rest is implementation.

## Authority before autonomy

An agent does not earn more scope because it sounds confident. It earns scope from explicit authority, evidence and a clean operating contract.

## Real fixes to real problems

A visible defect is a symptom. Find the mechanism, name the failure class, check the blast radius, fix the baseline when possible, and pin the lesson so it is harder to repeat.

## Null is not failure. False certainty is.

Unknown is a real state. Missing evidence is not zero. An estimate is not observed fact. A projection is not a record. A PR is not merged because someone says it is.

## Get the money right

Financial outputs inherit the quality of the records underneath them. If cash, flows, lots, basis or continuity are unresolved, downstream analytics must degrade or withhold accordingly.

## The model is not the calculator

Use deterministic code for arithmetic, replay, reconciliation and invariants when possible. Use the model for interpretation, ambiguity, pattern recognition and judgment around the edges.

## Preview before mutation

A consequential write should expose its expected state change before the write. The preview and commit path should share the same economic truth function whenever possible.

## Stop is a successful outcome

If the task crosses a protected boundary, lacks evidence, contradicts authority, or cannot be completed safely inside scope, stop precisely. Name what blocks the action and what would unblock it.

## Scope-OUT matters

A good task says what not to touch. "While I am here" is where disciplined agent work turns into accidental refactoring.

## Latest authority carries forward

When the human has answered a decision, preserve it. Do not charge them the re-ask tax because context moved to another model, session or worker.

## Claims require state transitions

Implemented, pushed, PR open, merged and deployed are different states. Say the state that can actually be proved.

## Every failure should improve the operating system

The best rules are paid for by incidents. Capture the mechanism, not just the story.
