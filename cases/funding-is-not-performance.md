# Funding Is Not Performance

## Failure
A simple start/end portfolio ratio remained calculable while external cash movements were unresolved. Deposits could appear as investment gains.

## Root mechanism
The system treated a fallback calculation as a valid answer instead of asking whether the fallback measured the thing the user asked for.

## Rule paid for
Performance readiness comes before performance calculation.
