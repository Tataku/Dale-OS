# Absence Is Not Agreement

## Failure
A canonical non-zero cash balance had no mirror row. The classifier treated the missing mirror as if there were no disagreement and reported the account reconciled.

## Root mechanism
A comparison that only runs when both values exist turned absence into a clean fallthrough state.

## Rule paid for
Missing evidence cannot prove agreement. Canonical non-zero + missing mirror is drift.
